# Installation

PRISM-G is available as a GitHub repository. To install from source, first clone the repository and then install the package using **pip** from the source directory:

```bash
git clone https://github.com/alejocrojo09/prismg.git
cd prismg
pip install -e .
```
PRISM-G requires the following dependencies:

1. numpy >= 2.3.0
2. pandas >= 2.3.2
3. scikit-learn >= 1.7.2
4. scipy >= 1.16.1
5. matplotlib >= 3.10.6
